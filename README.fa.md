# LBCreator

**LBCreator** یک پلاگین ساخت لیدربورد داینامیک برای [PocketMine-MP](https://pmmp.io) (نسخه API 5) است.
این پلاگین، پلاگین‌های دیگر را اسکن می‌کند، آمارهای (getter) اون‌ها رو پیدا می‌کنه و بدون نوشتن حتی یک خط کد، اون‌ها رو به لیدربورد (Floating Text) تبدیل می‌کنه.

> ریپازیتوری: <https://github.com/JustRohams/LB-Creator>

## ویژگی‌ها

- ساخت لیدربورد برای **هر پلاگین فعال** با پیدا کردن خودکار آمار از طریق Reflection
- منوی فرمی (`/lbc`) و ساب‌کامندهای کامل
- لیدربورد به‌صورت Floating Text با آپدیت خودکار
- تنظیم عنوان، متن پایانی، تعداد بازیکن (۱ تا ۵۰)، رنگ‌ها و ظاهر
- ذخیره‌سازی با YAML یا JSON همراه با بکاپ خودکار
- کش کردن نتایج برای سبک موندن سرور
- ایونت‌های مخصوص توسعه‌دهندگان
- بدون نیاز به هیچ کتابخانه (virion) خارجی

## پیش‌نیازها

- PocketMine-MP با API 5.0.0 به بعد
- PHP 8.1 به بعد

## نصب

۱. فایل `.phar` رو دانلود کن (یا با DevTools از سورس بساز).
۲. داخل پوشه `plugins/` سرور بذار.
۳. سرور رو ری‌استارت کن.

## دستورات

| دستور | توضیح | پرمیشن |
|-------|-------|--------|
| `/lbc` | باز کردن منوی اصلی | `lbcreator.command` |
| `/lbc create [plugin] [stat] [limit]` | ساخت لیدربورد در موقعیت شما | `lbcreator.create` |
| `/lbc delete <id>` | حذف لیدربورد | `lbcreator.delete` |
| `/lbc teleport <id>` | انتقال لیدربورد به موقعیت شما | `lbcreator.teleport` |
| `/lbc edit <id> [limit\|title\|end\|stat] [value]` | ویرایش لیدربورد | `lbcreator.edit` |
| `/lbc list` | لیست لیدربوردها | `lbcreator.list` |
| `/lbc reload` | ریلود تنظیمات و پیام‌ها | `lbcreator.reload` |
| `/lbc help` | راهنما | `lbcreator.help` |

همه پرمیشن‌ها به‌صورت پیش‌فرض مخصوص `op` هستند. دستورات فقط داخل بازی قابل استفاده‌اند.

### مثال

```
/lbc create MyPlugin kills 10
/lbc edit 1 title Top Killers
/lbc teleport 1
```

## نحوه کار

پلاگین، پلاگین هدف و آبجکت‌های داخل پراپرتی‌هاش رو برای متدهای عمومی به شکل `getSomething()` بررسی می‌کنه.
هر کدوم به‌عنوان یک «آمار» قابل انتخاب می‌شه. در هر آپدیت، getter مربوطه برای هر بازیکن **آنلاین** صدا زده می‌شه و نفرات برتر مرتب و نمایش داده می‌شن.

### محدودیت‌ها

- فقط بازیکنانی که **الان آنلاین** هستن رتبه‌بندی می‌شن.
- آمار فقط وقتی پیدا می‌شه که پلاگین هدف اون رو با یک getter (بدون آرگومان یا با آرگومان `Player`) که عدد برمی‌گردونه در دسترس گذاشته باشه.
